```bash

```

「对这条科技新闻执行一次五维完播爆款雷达体检」
```

没有繁琐设置，打字即刻出片。

## 🛠️ 两大核心工程机制

### 机制一：爆款切入视角三初稿顾问（不盲选、看着挑）
模糊需求或面对一条热点时，流水线绝不直接盲目生成，而是秒级给出 **3 套差异化爆款解读方案**：

```
┌────────────────────────────────────────────────────────┐
│               💡 爆款切入视角三初稿顾问提案库              │
├────────────────────────────────────────────────────────┤
│ 视角 A【搞钱红利视角】: 普通人如何借势新技术抢占红利、一人跑通变现 │
│ 视角 B【认知反差视角】: 颠覆行业传统共识、揭秘巨头为什么做错反直觉 │
│ 视角 C【行业洗牌视角】: 全行业面临底层重构、传统业务淘汰倒计时    │
└────────────────────────────────────────────────────────┘
```
创作者仅需回复对应选项，流水线立即按照选定策略生成适配度最高的文案与节奏。

---

### 机制二：五维视频号完播爆款雷达（出片必体检）
每条成片渲染完毕后，系统自动执行**五维客观质检门禁**，生成雷达体检单：

* **1. 黄金前三秒停留率 (Hook)**：主标题双行严格控制在 10 字以内，采用暖金双色微光渐变，秒级刺穿痛点；
* **2. 第 0 秒封面成活率 (First-Frame)**：自动化扫描第 0 秒画面亮度与色彩饱和度，彻底消灭黑屏死穴；
* **3. 去机器味口语网感 (Copywriting)**：行首强制原生彩色 Emoji（⚡ 💡 🎯），禁止任何生硬模板药丸框；
* **4. 纯净呼吸感与留白 (Clean Screen)**：成片底部彻底纯净留白，严禁出现免责声明或创作者计划杂音；
* **5. 短频推流完播率 (Retention Loop)**：成片时长精准控制在 5~13 秒，长图等宽平滑扫视，天生触发重复播放。
