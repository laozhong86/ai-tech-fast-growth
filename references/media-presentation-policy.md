# 原素材视窗智能展示与长图垂直滚动呈现规范 (Media Window Dynamic Presentation Policy)

在极简科技快讯短视频中，素材画面的呈现直接决定了视频的前三秒停留率与整体质感。本手册规范了各类素材在竖屏 1080×1920 媒体视窗下的动态呈现与算法决策规则。

---

## 一、 核心痛点与算法分流决策

1. **拒绝死板等比压缩**：科技快讯的素材形态极为多样，包含“标准横屏演示视频（16:9）”、“方形/通用插图（1:1 或 4:3）”以及**“推特长文截图/技术论文/长图代码（高长宽比，如 1:2 或 9:16）”**。如果对长截图机械化地执行缩小补黑边（Letterboxing），会导致整张长图缩成一个细条居中摆放，文字彻底模糊不可读，观感极其割裂。
2. **沉浸式视窗基准决策**：
   媒体视窗尺寸设定为 `w = 936, h = 526`，视窗自然宽高比基准为：
   $$R = \frac{936}{526} \approx 1.7795$$
   
   判定规则只有一条：**素材一律铺满视窗，溢出部分用平滑滚动或平移展示，严禁缩小补边！**

---

## 二、 视窗呈现决策矩阵

| 素材类型 | 宽高比 ($A = W / H$) | 相对视窗特征 | 视窗呈现决策 (`presentationMode`) | 渲染滤镜与动态行为 |
| :--- | :---: | :--- | :--- | :--- |
| **偏高素材**（含长图、长截图、推特长文） | **$A < R - 0.05$** | 比视窗更“高” | **垂直平滑扫视 (`vertical_scroll`)** | 等宽铺满 936px；`y` 轴由 0 平滑推到 `ih-526`；首帧停在顶部，文末预留停顿 |
| **偏宽素材**（超宽全景、代码长行） | **$A > R + 0.05$** | 比视窗更“宽” | **水平平移扫视 (`horizontal_pan`)** | 等高铺满 526px；`x` 轴由 0 平滑推到 `iw-936`；首帧停在左侧，末尾预留停顿 |
| **天然吻合**（标准 16:9 横屏） | **$\lvert A - R \rvert \le 0.05$** | 比例吻合 | **直接铺满 (`exact_fill`)** | 等比放大铺满 936×526 视窗后微量裁切，居中展示无黑边 |

### 🚫 明令禁止（Hard Bans）：

- **严禁缩小补边（Letterbox Ban）**：任何使用 `scale=936:526:force_original_aspect_ratio=decrease,pad=936:526...` 的缩小居中留黑边滤镜一律禁止！
- **严禁片头截取半截**：偏高长图必须严格从 `y = 0` 起始，保证第 0.0 秒完整呈现长图顶部的作者头像、标题与首段要点。

---

## 三、 核心滤镜公式与匀速阅读控制

在视窗 `(w=936, h=526)` 下，针对偏高长图的垂直滚动算法标准：

```text
fps=30,scale=936:-1,crop=936:526:0:'(ih-526)*min(1,t/(duration-1.5))',setsar=1,format=yuv420p
```

### 关键控制点解析：
1. **`scale=936:-1`**：素材强制等宽填满 936px 视窗，高度按原图比例自适应缩放，确保推文中的字号放大到手机端舒适可读的大小；
2. **首帧完整性（`t=0.0s`）**：在视频第 0 秒，`min(1, 0) = 0`，垂直偏移量 `y = 0`，完美呈现推文顶部作者、时间戳与第一段话，直接支撑首帧封面质检门禁；
3. **末尾静止驻留机制（`min(1, t / (duration - 1.5))`）**：
   在总时长（如 12 秒）的最后 1.5 秒内，表达式取值达到 `1`，滚动平滑到位并保持静止驻留，观众能在视频收尾时完整看清长图末尾的关键结论或数据，彻底解决“滚到一半就被切走”的突兀感。
4. **水平平移同理**：
   偏宽素材将偏移作用在 `x` 上：
   ```text
   fps=30,scale=-1:526,crop=936:526:'(iw-936)*min(1,t/(duration-1.5))':0,setsar=1,format=yuv420p
   ```
