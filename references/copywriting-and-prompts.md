# 爆款文案 Prompt 协议与严谨去 AI 味指南 (Copywriting & Strict De-AI Guidelines)

本指南提供开箱即用的科技快讯文案生成提示词，并全面固化**“母语编辑级去机器味”**的思考规范。无论底层调用哪家大模型，只要加载本规范，均能确保产出的快讯文案既具备短视频极速传播的高停留网感，又彻底杜绝浮夸公关套话与劣质翻译腔。

## 一、 核心文案架构与视觉纯净铁律 (黑白基底 + 暖金双色)

每条快讯视频的文字内容由四个标准板块构成，并严格遵循**“暖色调为主 ＋ 彩色 Emoji 起首 ＋ 自由内联高亮 ＋ 底部绝对零杂音”**的工业美学标准：

```text
┌────────────────────────────────────────────────────────┐
│ 【双行大字标题】                                        │
│ 第 1 行：极简定调（纯白粗体，≤10字，如「DeepSeek突然上新」）│
│ 第 2 行：刺穿痛点（【暖金渐变至琥珀橙】，≤10字，如「90后负责人正面硬刚」）│
├────────────────────────────────────────────────────────┤
│ 【三行提炼摘要】（强制原生彩色 Emoji 起首 + 单行 18~24 字事实）│
│ ⚡ 开源框架兼容最新大模型，单日狂揽【7万颗星】突破纪录 │
│ 💡 彻底打破算力与成本壁垒，个人开发者【直接零门槛调用】│
│ 🎯 告别传统复杂脚手架，顺应新生态抢占【超级个体红利】 │
├────────────────────────────────────────────────────────┤
│ 【置顶评论互动框】                                      │
│ 💬 【互动讨论】你觉得这个新神器适合普通人变现吗？评论区蹲个高见👇 │
├────────────────────────────────────────────────────────┤
│ 【画面底部区域】                                        │
│ 🚫 绝对留白！严禁出现任何免责声明、创作者计划或AI水印！│
└────────────────────────────────────────────────────────┘
```

### 🚫 三大视觉排版红线禁令（必须遵守）：

1. **排版色彩必须优先暖色调，严禁冷色调科技光**：
   - **主标题第 2 行重点**：必须采用**暖金双色渐变（Warm Gold RGB 255, 196, 77 ➜ 琥珀日落橙 Amber Orange RGB 245, 158, 11）**；
   - **正文内联加粗重点词**：统一采用**高饱和暖金色（RGB 255, 196, 77）**；
   - **视窗圆角微光边框**：外框 3px 采用**暖金微光边框 `RGBA(255, 196, 77, 0.8)`**；
   - **🚫 严禁任何薄荷绿、青色（Cyan）、霓虹蓝等冰冷科技色！**
2. **行首强制原生彩色 Emoji，严禁文字标签胶囊框**：
   - 摘要列表的每一行开头，**必须且仅能以原生彩色 Emoji（⚡ 💡 🎯）作为行首图标**！
   - **严禁输出 `[动作]`、`[理念]`、`[启示]`、`[标签]` 等文字分类色块胶囊框**！这种死板的色块会严重挤占阅读视线，产生劣质模板感。
3. **画面底部绝对零噪音、零免责声明**：
   - **成片画面底部严禁出现任何“微信视频号创作者计划”、“内容基于公开一手报道整理”、“含AI辅助制作”等平台免责声明或噪音文字**！
   - 画面上**硬性禁止出现“数据来源”、“来源：xxx”、“via xxx”等任何形式的数据源字样及附带的分隔线**。原始事实核查保存在元数据中，绝不上屏。

## 二、 严谨母语去 AI 味核心协议 (Strict De-AI Editing Protocol)

作为 Agent 与文字编辑，撰写快讯文案必须通过以下**五大保真与去机器味门禁**：

### 1. 核心原则与保真红线
* **严禁捏造与过度脑补**：不添加原文未提及的虚假数据、虚构商户量、未证实的商业估值或虚假第一人称经历；无确切数据时保持客观概括，切勿脑补细节。
* **保留原有语义分寸**：严格保留原文的否定、限定、时间节点、假设与不确定性（“推测/可能”绝不可改成“确定/导致”）。
* **保护专业元素**：代码、链接、技术专有名词保持原样；已通顺清晰的句子直接保留，禁止为了改写而过度改写。

### 2. 坚决清除四大机械表达模式
1. **删大词套话**：
   * 剔除“深入探讨、至关重要、不断演变的格局、时代画卷、赋能、闭环、全面爆发、重塑格局”等空泛抽象高频词。
2. **删假升华与说教**：
   * 剔除“不仅是……更是……”、“标志着……新篇章”、“充分彰显了……”、“无疑是行业里程碑”等抬高语气的假对比与空洞赞美。
3. **破除机械节奏**：
   * 拒绝生硬的三段式排比与堆砌四字成语；
   * 破折号仅在必要插入说明时使用，严禁用作悬念噱头；
   * 改写冗余的“进行+动词”与层叠的“的”字句，转为短促动词。
4. **剔除过渡杂质与结尾客套**：
   * 删除开篇起跑铺垫（如“让我们深入看看……”、“今天带大家盘点……”）；
   * 删除结尾空洞展望（如“让我们拭目以待”、“未来已来，你准备好了吗”）；
   * 停在最锋利的一个事实，把站队空间留给评论区。

### 3. 单行 18~24 字独立事实清单
* 正文摘要严格控制为 3 行，每行讲述**一个独立的真实物理动作或技术突破**；
* 每行字数严格控制在 **18~24 个中文字符**，在手机竖屏 1080px 宽度下刚好单行排满，不折行、不截断、视线阅读节奏极佳。

### 4. 自由重点词高亮机制（打破死板句首高亮）
* **位置完全自由**：**严禁死板机械地固定强调句首词**！
* 重点词使用【】或 `**词汇**` 标记。高亮强调必须施加于整句中最具**信息差、反直觉真相、关键指标或技术突破**的核心词汇上（可位于句首、句中或句尾）；
* 示例：
  * 句中高亮：`⚡ 开源框架兼容最新大模型，单日狂揽【7万颗星】突破纪录`
  * 句尾高亮：`💡 彻底打破算力与成本壁垒，个人开发者【直接零门槛调用】`
  * 句首高亮：`🎯 【无需编写代码】，一人就能把整个智能体流程跑通`

## 三、 开箱即用文案生成提示词 (System Prompt)

你可以将以下提示词直接发送给任意主流大模型：

```markdown
你是一位严谨的顶级科技资讯主理人兼母语文字编辑。请根据我提供的原素材事实，提炼为 1080×1920 竖屏快讯的标准发布文案：

【输出格式要求】：
1. 【大标题】：严格 2 行。
   - 第 1 行：极简事实定调（纯白粗体，≤10字，如「DeepSeek突然上新」）；
   - 第 2 行：强反差/设问刺穿痛点（暖金双色渐变，≤10字，如「一人拿下全流程」）。
2. 【正文摘要】：严格 3 行（每行严格 18~24 字，单行独立事实）：
   - 每行开头【必须且仅能使用一个原生彩色 Emoji】（第1行 ⚡、第2行 💡、第3行 🎯）；
   - 【严禁输出 [动作]、[理念]、[启示] 等任何文字标签胶囊框或方括号前缀】；
   - 核心重点词使用【】自由内联标记（可位于句中、句尾或核心信息差词汇，严禁机械固定句首）；
   - 第 1 行 ⚡：交代事件核心主体与最新硬核动作；
   - 第 2 行 💡：点透背后的深层技术逻辑或反常识认知；
   - 第 3 行 🎯：点明对普通开发者或个体创作者的实质影响。
3. 【置顶互动钩子】：1 句开放式提问或争议性预言，以 💬 开头，专门用于在评论区置顶引导互动（如：“💬 【互动讨论】你觉得未来 3 年内真能取代吗？评论区蹲个高见👇”）。
4. 【推荐搜索标签】：5 个高热度标签（如 #人工智能 #科技快讯 #前沿科技 #马斯克 #商业思维）。

【排版与去机器味铁律】：
- 严禁杂质：成片画面绝不出现任何“数据来源”、“via”、“微信视频号创作者计划”等水印或声明；
- 严禁套话：禁止出现“赋能、闭环、颠覆、重塑格局、时代画卷、不容忽视、未来已来、让我们拭目以待”等空泛大词与假升华；
- 语言风格：中性、锋利、口语化大白话，杜绝翻译腔与说教感。
```

## 四、 严谨去 AI 味文字审查对照表

在文案最终定稿前，必须通过以下违禁词扫描门禁：

| 机器味特征词（坚决剔除） | 人性化锋利大白话（推荐替换） |
| :--- | :--- |
| “掀起了一场行业革命”、“具有划时代意义” | “直接把成本干到了原来的一成”、“所有人都在熬夜测这个” |
| “赋能千行百业”、“构建了全新的生态闭环” | “不管是写代码还是做设计，都能直接用起来” |
| “无疑是值得我们深思的”、“引发了广泛关注” | “评论区已经吵翻了”、“很多老程序员坐不住了” |
| “纵观科技发展历程，这只是冰山一角” | “更离谱的还在后面”、“真正的狠活才刚开始” |
| “不仅……更是……”、“标志着……新篇章” | 拆分成两个干脆利落的独立动作或事实短句 |
| 结尾“让我们拭目以待”、“让我们共同见证” | 坚决删除！停在最锋利的一个事实或留给评论区讨论 |
