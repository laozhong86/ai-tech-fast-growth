# 爆款文案 Prompt 协议与去 AI 味指南 (Copywriting & Prompts)

本指南提供开箱即用的 AI 文案生成提示词，并集成严谨的“去机器味真实感润色”标准，确保产出的快讯文案既具备短视频极速传播的网感，又杜绝浮夸公关套话。

---

## 一、 核心文案架构与视觉纯净铁律 (黑白基底 + 暖金双色)

每条快讯视频的文字内容由四个标准板块构成，并严格遵循**“暖色调为主 ＋ 彩色 Emoji 起首 ＋ 底部绝对零杂音”**的工业美学标准：

```text
┌────────────────────────────────────────────────────────┐
│ 【双行大字标题】                                        │
│ 第 1 行：极简定调（纯白粗体，≤10字，如「DeepSeek突然上新」）│
│ 第 2 行：刺穿痛点（【暖金渐变至琥珀橙】，≤10字，如「90后负责人正面硬刚」）│
├────────────────────────────────────────────────────────┤
│ 【三行提炼摘要】（强制使用原生彩色 Emoji 开头！）     │
│ ⚡ 【核心动作】开源框架兼容 Claude Code，单日狂揽7万星 │
│ 💡 【技术理念】不做平庸模仿，要做出让世界巨头跟进的创新 │
│ 🎯 【行业启示】一切皆插件，国内开发者零门槛直接用起来   │
├────────────────────────────────────────────────────────┤
│ 【置顶评论互动框】                                      │
│ 💬 【互动讨论】你觉得国产智能体能超越海外大厂吗？评论区蹲个预言 │
├────────────────────────────────────────────────────────┤
│ 【画面底部区域】                                        │
│ 🚫 绝对留白！严禁出现任何免责声明、创作者计划或AI水印！│
└────────────────────────────────────────────────────────┘
```

### 🚫 三大视觉排版红线禁令（必须遵守）：
1. **排版色彩必须优先暖色调，严禁冷色调科技光**：
   - **主标题第 2 行重点**：必须采用**暖金双色渐变（Warm Gold RGB 255, 196, 77 ➜ 琥珀日落橙 Amber Orange RGB 245, 158, 11）**；
   - **正文内联加粗重点词**：统一采用**高饱和暖金色（RGB 255, 196, 77）**；
   - **视窗圆角微光边框**：外框 3px 采用**暖金微光边框 `RGBA(255, 196, 77, 0.8)`**；
   - **🚫 严禁任何薄荷绿、青色（Cyan）、霓虹蓝等冰冷科技色！**
2. **行首强制原生彩色 Emoji，严禁文字标签胶囊框**：
   - 摘要列表的每一行开头，**必须且仅能以原生彩色 Emoji（如 ⚡ 💡 🎯 🔥 🚀）作为行首图标**！
   - **严禁输出 `[动作]`、`[理念]`、`[启示]`、`[标签]` 等文字分类色块胶囊框**！这种死板的色块会严重挤占阅读视线，产生劣质模板感。
3. **画面底部绝对零噪音、零免责声明**：
   - **成片画面底部严禁出现任何“微信视频号创作者计划”、“内容基于公开一手报道整理”、“含AI辅助制作”等平台免责声明或噪音文字**！
   - 平台合规声明（如包含AI内容标识、原创声明）**仅限在后台上传草稿箱时作为系统表单勾选项**，绝对不能印在视频画面上破坏构图！底部必须彻底留白，预留给平台底栏交互。

## 二、 开箱即用文案生成提示词 (System Prompt)

你可以将以下提示词直接发送给任意主流大模型（如豆包、ChatGPT、DeepSeek、Kimi 等）：

```markdown
你是一个顶级视频号爆款科技资讯主理人。请根据我提供的原素材/资讯事实，提炼为新闻资讯类短视频的标准发布文案：

【输出格式要求】：
1. 【大标题】：严格 2 行。
   - 第 1 行：极简事实定调（10字以内，粗暴直接）；
   - 第 2 行：强情绪/强反差/设问刺穿痛点（10字以内，制造悬念）。
2. 【正文摘要】：严格 3 行（总字数控制在 60～100 字）：
   - 每行开头【必须且仅能使用一个原生彩色 Emoji】（第1行 ⚡、第2行 💡、第3行 🎯）；
   - 【严禁输出 [动作]、[理念]、[启示] 等任何文字标签胶囊框或方括号前缀】！
   - 核心重点短语使用【】标记高亮；
   - 第 1 行 ⚡：交代事件核心主体与最新硬核动作；
   - 第 2 行 💡：点透背后的深层技术逻辑或反常识认知；
   - 第 3 行 🎯：点明对普通开发者或行业的实质影响。
3. 【置顶互动钩子】：1 句开放式提问或争议性预言，以 💬 开头，专门用于在评论区置顶引导互动（如：“💬 【互动讨论】你觉得未来 3 年内真能取代吗？评论区蹲个预言👇”）。
4. 【视频号简介】：1 句互补的宏观行业洞察，附带 5 个高热度标签（如 #人工智能 #科技快讯 #前沿科技 #马斯克 #商业思维）。

【排版与语言铁律】：
- 严禁杂音：成片画面底部绝对不准出现任何“微信视频号创作者计划”、“内容基于公开一手报道整理”、“含AI辅助制作”等口号或免责文字；
- 严禁用词：禁止出现“颠覆、重塑格局、全面爆发、赋能、闭环、不容忽视、未来已来、让我们拭目以待”等公关腔与假升华；
- 语言风格：中性、锋利、口语化大白话，杜绝翻译腔与说教感。
```

## 三、 严谨去 AI 味文字审查对照表

在文案最终定稿前，必须通过以下违禁词扫描门禁：

| 机器味特征词（坚决剔除） | 人性化锋利大白话（推荐替换） |
| :--- | :--- |
| “掀起了一场行业革命”、“具有划时代意义” | “直接把成本干到了原来的一成”、“所有人都在熬夜测这个” |
| “赋能千行百业”、“构建了全新的生态闭环” | “不管是写代码还是做设计，都能直接用起来” |
| “无疑是值得我们深思的”、“引发了广泛关注” | “评论区已经吵翻了”、“很多老程序员坐不住了” |
| “纵观科技发展历程，这只是冰山一角” | “更离谱的还在后面”、“真正的狠活才刚开始” |
| 结尾强行正能量升华 | 停在最锋利的一个事实或留给评论区去站队 |
