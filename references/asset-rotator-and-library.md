# 资产顺序轮换调度与公共资源清单 (Asset Rotator & Resource Library)

本手册定义了开源公开项目 `ai-tech-fast-growth` 内置的核心视听资产矩阵及其自适应顺序轮换机制，确保创作者在连续批量出片时，既零门槛开箱即用、免去庞大私有素材库依赖，又杜绝连续出片视听雷同。

---

## 一、 为什么必须采用顺序轮换调度？

1. **规避 AI 纯随机化扎堆陷阱**：在素材库规模为轻量化矩阵时，使用纯随机数（`Math.random()`）极易产生“连续扎堆效应”，导致连续生成的 2~3 条视频抽中同一段背景或同一首背景音乐，给观众造成严重的视觉疲劳与廉价感。
2. **轻量游标持久化与环形轮换**：
   流水线通过本地轻量游标状态记录（如 `.local_workbench/asset-rotator-cursor.json`），每次执行成功后自动推进 1 位，在多套模板间做均匀的环形队列循环调度。

## 三、 轮换调度器运行逻辑

1. **自动轮换（默认行为）**：
   脚本在每次执行时，自动读取上次运行记录的轮换游标：
   $$\text{nextIndex} = (\text{currentIndex} + 1) \pmod{\text{totalCount}}$$
   确保下一次出片自动切换至下一组背景与配乐。
2. **手动强制指定（灵活覆盖）**：
   创作者可通过命令行参数显式覆盖：
   ```bash
   # 手动指定使用波纹背景与电子律动音乐
   node scripts/produce.mjs --url "..." --bg wave --bgm cyber
   ```
3. **音画安全标准**：
   * 原视频素材一律静音；
   * 背景音乐自动配置片尾 0.8 秒平滑淡出（`afade=t=out`），并在视频第 0.0 秒饱满发声，杜绝突兀截断或爆音。
