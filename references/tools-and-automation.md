# 自动化工具链体系与环境契约手册 (Tools & Automation Architecture)

为了实现极致平滑的端到端自动化体验，本技能对工具链实施严格的**“强依赖 ＋ 可选加速”**分层管理。**AI 严禁凭空猜测工具命令或重复排查环境，必须严格遵照本手册的标准工具契约执行**。

---

## 一、 工具链分层设计与定位矩阵

```text
┌────────────────────────────────────────────────────────┐
│  【强制依赖 · 核心底座】opencli                         │
│  - 作用：免登录/公开资讯抓取、长图长文截图、页面无感渲染 │
│  - 状态：必须安装（缺失则直接阻断并提示一键安装）       │
├────────────────────────────────────────────────────────┤
│  【可选增强 · 极速审校】Jev (TypeSafe System 1)        │
│  - 作用：毫秒级文案口播感、对抗式网感评审与结构化打分   │
│  - 状态：可选（未安装则自动平滑降级为大模型 Prompt 审查）│
├────────────────────────────────────────────────────────┤
│  【可选增强 · 真实浏览器】Ego (ego-browser)            │
│  - 作用：真实用户登录态接管、复杂前端环境深度验证       │
│  - 状态：可选（未配置则自动使用 opencli 无头模式接管）   │
└────────────────────────────────────────────────────────┘
```

---

## 二、 数据采集双模式：轻量免依赖直连模式 与 opencli 全幅长图模式

### 1. 模式 A：【零依赖轻量模式】AI HOT 原生网络直连 (推荐，无需 opencli！)
* **核心价值**：**完全不依赖 opencli 或任何无头浏览器！** 使用纯 Node.js 原生标准网络请求，零配置直连 AI HOT 官方 Agent 匿名免密接口（`https://aihot.news/api/v1/agent`）；
* **使用场景**：快速获取当日热点资讯、按关键词搜索一手新闻、提取精炼中文摘要与推荐理由；
* **开箱即用脚本**：
  ```bash
  # 抓取今日过去 24 小时精选前 5 条一手资讯
  node scripts/fetch-aihot.mjs --latest 5

  # 按关键词搜索最近 7 天一手热点资讯 (如 DeepSeek)
  node scripts/fetch-aihot.mjs --search "DeepSeek" --out-dir "tmp/aihot-deepseek"

  # 抓取当前全网实时热点榜
  node scripts/fetch-aihot.mjs --hot
  ```

### 2. 模式 B：【高清长图模式】opencli 像素级全幅截图 (用于推文长图)
* **核心价值**：当素材是一整条推特长推文或技术论文长图，需要将其制作成长图等宽垂直滚动扫视短视频时，通过 `opencli` 截取完整高清全屏截图；
* **使用脚本**：
  ```bash
  node scripts/fetch-content.mjs --url "https://x.com/username/status/123456" --out-dir "tmp/article_01"
  ```

## 三、 可选加速工具一：Jev 结构化决策 (可选)

### 1. 业务定位与请求地址
* **能力**：基于 TypeSafe 的极速小模型，专门在毫秒级别对提炼出的快讯台词进行“口语化程度、节奏紧凑度、去公关套话、结构痛点”四维度对抗评审。
* **请求地址**：默认由其官方客户端程序直接连接官方标准接口网关，严禁在技能内硬编码任何私有中转链接。

### 2. 【绝对零密钥铁律】与凭据隔离
* **严禁硬编码密钥**：**本技能作为面向大众的开源产品，全技能文件、配置与脚本中绝对禁止出现任何私有 API 密钥、Token 或敏感密码**！
* **凭据规范**：若用户或高级创作者本地启用了 Jev，凭据仅能通过其本地操作系统的受保护环境变量（如 `TYPESAFE_API_KEY`）在外部隐式提供，技能本身对密钥完全无感知。

### 3. 平滑降级契约 (Fallback)
* **检测机制**：运行 `scripts/doctor.sh` 自动判定系统是否具备 Jev 环境及本地有效授权；
* **零门槛免费降级**：**若未安装 Jev 或未配置本地密钥，流水线自动静默采用 [references/copywriting-and-prompts.md](copywriting-and-prompts.md) 中的去 AI 味 System Prompt 规则自审**。粉丝无需花一分钱、无需购买或配置任何密钥，全流程 100% 顺畅闭环，严禁报错阻断。

## 四、 可选加速工具二：Ego 真实浏览器 (可选)

### 1. 业务定位
* **能力**：在需要加载真实用户登录态或复杂多因子验证的场景下，通过 Chromium 真实窗口驱动完成交互。

### 2. 平滑降级契约 (Fallback)
* **检测机制**：若系统中未配置 `ego` 或未开启桌面浏览器会话；
* **降级策略**：**默认由 `opencli browser` 无头模式接管全部页面抓取与截图工作**，或通过本地发布脚本直接对接官方接口，无需人工介入打开图形界面。

## 五、 开工前一秒就绪诊断：scripts/doctor.sh

在任何执行开始前，AI 必须首先运行内置诊断工具：
```bash
bash scripts/doctor.sh
```
* **退出码为 0**：代表核心环境与 `opencli` 强依赖均已就绪，立即推进后续步骤；
* **退出码为 1**：脚本会明确输出缺失的组件及单行安装命令，用户或系统完成安装后即可秒级恢复。
