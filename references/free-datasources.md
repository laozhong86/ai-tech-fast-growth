# 免会员公开一手资讯数据源指南 (Free & Open Data Sources)

本手册专为开源与粉丝群体设计，**完全脱离任何需要付费订阅、会员登录或私有抓取的封闭平台**，确保任何零基础创作者均可零成本获取一手优质素材。

---

## 一、 渠道采集优先级硬门禁 (Channel Priority Gate)

在进行选题与素材采集时，**必须严格按照以下三级梯队依次调用，严禁通过通用搜索引擎（如百度、Bing、搜狗等）随机抓取二手媒体或传统门户新闻**：

```text
┌────────────────────────────────────────────────────────┐
│ 【第一优先级 · 首选】AI HOT 资讯                        │
│ 地址：https://aihot.virxact.com/                       │
│ 特征：全网免费一手聚合，自带精炼中文事实，零广告无水印 │
├────────────────────────────────────────────────────────┤
│ 【第二优先级】科技大佬公开推文 (X/Twitter)              │
│ 目标：马斯克、奥特曼、黄仁勋、Karpathy、杨立昆等一手推文│
│ 特征：全球公信力、推文排版极简干净，支持全幅长图截取   │
├────────────────────────────────────────────────────────┤
│ 【第三优先级】开源趋势榜 (GitHub Trending / HF Spaces)  │
│ 目标：https://github.com/trending 及 HuggingFace      │
│ 特征：硬核项目演示动图、高精 README 成果对比            │
└────────────────────────────────────────────────────────┘
```

### 🚫 严禁违规行为与红线禁令：
1. **严禁搜二手门户通稿**：绝对禁止直接用搜索引擎搜索“XX最新消息”然后抓取传统新闻网站（如中国网财经、新浪网、搜狐网等门户网站）。
2. **为什么严禁二手门户？**
   - **画面极度杂乱**：传统新闻网站充斥着“低碳中国”等绿色大横幅、网站 Logo、广告弹窗、编辑推荐和热线电话，视频画面呈现后显得极度廉价与业余（严重影响观众留存）；
   - **内容时效滞后**：传统媒体通稿通常是对海外推文或一手论文翻译数天后的二手甚至三手解读，早已丧失短视频传播的黄金首发时效。

## 二、 选题黄金三要素（烤妹儿起号法则）

在 AI 科技领域，千万不要做晦涩难懂的学术代码搬运，观众买单并顺手转发到微信群和朋友圈的核心驱动力只有三样：

```text
【大佬】＋【搞钱】＋【反差】
```

1. **大佬八卦与言论**：马斯克（Elon Musk）、奥特曼（Sam Altman）、黄仁勋（Jensen Huang）、扎克伯格（Mark Zuckerberg）等世界级名人的最新发言、针锋相对与暴论预测（自带国民级流量与公域信任）。
2. **前沿逆天工具**：普通人一看就觉得“时代变了”、“这都能做到”的炸裂级应用（如一键生成完整电影、物理世界机器人最新突破、颠覆日常工作的效率神器）。
3. **行业内幕与反常识认知**：打破大众固有认知的信息差（例如“为什么大厂高薪裁员却狂买算力”、“开源大模型如何零成本干翻商业闭门模型”）。

## 三、 零成本素材抓取与使用规范

1. **原图与长截图保存**：
   - 看到优质推文或新闻，使用浏览器自带长截图工具，保存推文完整长图；
   - 看到演示视频，提取 3~5 秒最炸裂的视觉高潮片段（如机器人翻跟头、生成效果对比）。
2. **事实追溯与二次求证**：
   - 二手解读仅作为线索提示，成文前核对一次数字与关键事件主体，确保事实真实无误；
   - 严禁搬运未经证实且容易引起恐慌的虚假涉政、涉财谣言。
3. **彻底脱敏与独立品牌化**：
   - 成片画面严禁出现“来自XX网站”、“XX会员专享”等外部数据源标签或水印；
   - 始终以自身视频号创作者的主理人口吻发布。
